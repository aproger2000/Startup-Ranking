Админ-панель

Добавление, редактирование и массовая загрузка компаний в базу рейтинга.

← к публичному рейтингу

Ключ доступа

Нужен серверный X-Api-Key (переменная окружения ADMIN_API_KEY). Ключ хранится только в этом браузере.

Добавить компанию

Скор считается автоматически на сервере по формуле из методологии — вручную его вводить не нужно.

Раздел рейтинга (young/mature/aged/early_stage) вычисляется автоматически по году основания — вручную указывается только признак ранней стадии ниже, он приоритетнее возраста. Компании старше 15 лет (и не отмеченные как ранняя стадия) в рейтинг не попадают вообще — считаются не стартапом.

Массовая загрузка (JSON)

Вставьте массив объектов с теми же полями (обязательны name и sector). Существующие записи (по паре название+отрасль) обновятся, новые — создадутся. Этим же способом сможет пользоваться автоматическая задача пополнения базы.
